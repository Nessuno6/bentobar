**BentoBar 2.2.1-notch.3**: fixes the crash when checking for app updates and keeps all `2.2.1-notch.2` cross-device link fixes.

### Install
> **Note:** If you are upgrading from `2.2.1-notch.1` (or `2.2.1-notch.2`), install this `BentoBar.apk` manually once because those earlier builds crashed during the in-app update check. From `2.2.1-notch.3` onward, **Check now** and automatic update notifications work directly in-app.

1. Download **BentoBar.apk** below on your device and open it (allow your browser or Files to install apps if asked; upgrades directly over `2.2.1-notch.*` and `1.7.1-notch.*`).
2. Open BentoBar. It says what its accessibility service does and asks whether you agree; **Agree** opens Android's Accessibility settings. The first time, Android marks the switch as a *restricted setting*: tap it once, then in BentoBar tap **Setup** › **App info** › **⋮** › **Allow restricted settings**, and turn BentoBar on again.
3. *(Optional)* To read per-app CPU/memory lists, hardware temperatures, battery cycles/health, or accessory batteries, allow **Shizuku** under **Setup › Shizuku** (works over ADB or root) or allow root (`su`) when your root manager prompts.

### What's new
- **Fixed crash in "Check for updates" (`Http` / `Online` / `HttpTransport` / `Updates`):**
  - `Http.get` and `Http.key` now use `Online.serviceOrNull(host)` instead of `Online.serviceOf(host)`, fixing the `NoSuchElementException` crash when querying GitHub (`Host.GITHUB`) after the upstream `2.2.1` merge added per-service rate limiting.
  - `HttpTransport.get` now queries `Http.key(host)` only for hosts that take an API key (`host.keyName != null`).
  - Replaced `Updates.asking` boolean flag with an atomic in-flight request count and guarded `SetupPage`'s background update check thread against late UI callbacks.
- **Includes everything from `2.2.1-notch.2` & `2.2.1-notch.1`:** cross-device battery link picker/connection timeouts and `play-services-dtdi` `16.0.0-beta03`, optional Shizuku support with `su` fallback, upstream BentoBar 2.1.0–2.2.1, and all fork features.
