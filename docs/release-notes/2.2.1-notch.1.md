**BentoBar 2.2.1-notch.1**: merges upstream BentoBar 2.1.0–2.2.1 and adds optional **Shizuku** support alongside root.

### Install
1. Download **BentoBar.apk** below on your device and open it (allow your browser or Files to install apps if asked; upgrades directly over `1.7.1-notch.*`).
2. Open BentoBar. It says what its accessibility service does and asks whether you agree; **Agree** opens Android's Accessibility settings. The first time, Android marks the switch as a *restricted setting*: tap it once, then in BentoBar tap **Setup** › **App info** › **⋮** › **Allow restricted settings**, and turn BentoBar on again.
3. *(Optional)* To read per-app CPU/memory lists, hardware temperatures, battery cycles/health, or Samsung accessory batteries, allow **Shizuku** under **Setup › Shizuku** (works over ADB or root) or allow root (`su`) when your root manager prompts.

**Optional online items.** Only **Weather** and **Air quality & UV** (Open-Meteo, no key), **Exchange rates** (Frankfurter, no key), **Flight** (AirLabs, with a free key of your own) and **US stocks** (Finnhub, with a free key of your own) go online, and only after you set them up; **Setup › Online services** switches each off again. **About › Privacy** in the app says exactly what is sent and when.

### What's new
- **Shizuku support (optional).** Prefers [Shizuku](https://shizuku.rikka.app/) (`moe.shizuku.manager.permission.API_V23`) when Shizuku is running and allowed, running read-only queries inside an isolated `UserService`, and falls back automatically to root (`su`) when Shizuku isn't available or a sensor/database requires UID 0 (for instance, when Shizuku runs over ADB at UID 2000). Added a **Setup › Shizuku** row showing current status and server mode (ADB or root) with **Allow** and **Open Shizuku** actions, plus the Shizuku API attribution in **About**.
- **Upstream BentoBar 2.1.0–2.2.1:**
  - **Left, Middle and Right strip areas** (plus automatic wrapping across free status bar room, rebuilt Settings window, Remove deletes with Undo).
  - **16 new items** (Live activity, Camera and mic, Mirror, Prompter, Notification icons, Focus, Brightness, Keyboard light, Headphones and output, Connection, Screen time, Day progress, Sunset, Break reminder, plus Presenting mode and Behind-`‹` modes).
  - **Real CPU load counters & Network menu addresses** (sleeping CPU cores no longer over-report idle load; Network menu adds IP, IPv6, gateway, DNS and Private DNS).
- **Fork features retained:** external-display taskbar bar, glass blur controls, One UI icons/font/widget styling, optional root/Shizuku hardware sensors and per-app process lists, live/battery/item providers, home & lock screen widgets, and in-app GitHub updates.
